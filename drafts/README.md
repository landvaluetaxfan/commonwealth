# drafts/

Hand-written content in the format described in `../AUTHORING_FORMAT.md`.

Nothing here is loaded by the game. These are source files that an agent
converts into `content/*.js`. Write here, convert, run `npm run check`, commit.

Keeping drafts in the repo means the prose is versioned separately from the
generated structure, so you can rewrite an event's text without hunting through
JavaScript for it.
